## 阅读顺序建议

1. 先看仓库根 [README](../README.md) 的「架构」与「两个绕不过去的坑」；
2. 想复现构建 → 环境体检报告 + [engine/README.md](../engine/README.md)；
3. 想改功能 → P0/P1 说明里都有「代码位置」小节；
